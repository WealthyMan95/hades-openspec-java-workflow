# 团队安装指南

本文说明如何把 `hades-openspec-workflow` 发布到 GitHub，并让团队成员 clone 后安装到 Codex。

## 维护者：发布到 GitHub

在插件目录初始化仓库：

```bash
cd ~/plugins/hades-openspec-workflow
git init
git branch -M main
git add .
git commit -m "feat: add Hades OpenSpec workflow plugin"
```

在 GitHub 创建仓库，建议名称：

```text
hades-openspec-workflow
```

然后添加远程并推送：

```bash
git remote add origin https://github.com/<owner>/hades-openspec-workflow.git
git push -u origin main
```

如果使用 SSH：

```bash
git remote add origin git@github.com:<owner>/hades-openspec-workflow.git
git push -u origin main
```

## 团队成员：macOS / Linux 安装

clone 插件源码：

```bash
git clone https://github.com/<owner>/hades-openspec-workflow.git ~/plugins/hades-openspec-workflow
```

如果目录已存在：

```bash
cd ~/plugins/hades-openspec-workflow
git pull
```

如果 `~/.agents/plugins/marketplace.json` 不存在，创建 personal marketplace：

```bash
mkdir -p ~/.agents/plugins
cat > ~/.agents/plugins/marketplace.json <<'JSON'
{
  "name": "personal",
  "interface": {
    "displayName": "Personal"
  },
  "plugins": [
    {
      "name": "hades-openspec-workflow",
      "source": {
        "source": "local",
        "path": "./plugins/hades-openspec-workflow"
      },
      "policy": {
        "installation": "AVAILABLE",
        "authentication": "ON_INSTALL"
      },
      "category": "Productivity"
    }
  ]
}
JSON
```

如果 marketplace 已经存在，不要整体覆盖文件。只确认 `plugins` 数组里包含以下条目：

```json
{
  "name": "hades-openspec-workflow",
  "source": {
    "source": "local",
    "path": "./plugins/hades-openspec-workflow"
  },
  "policy": {
    "installation": "AVAILABLE",
    "authentication": "ON_INSTALL"
  },
  "category": "Productivity"
}
```

安装插件：

```bash
codex plugin add hades-openspec-workflow@personal
codex plugin list
```

安装或更新后，重启 Codex App，或在目标项目中新开一个 Codex 会话。

## 团队成员：Windows 安装

clone 插件源码：

```powershell
git clone https://github.com/<owner>/hades-openspec-workflow.git "$env:USERPROFILE\plugins\hades-openspec-workflow"
```

如果目录已存在：

```powershell
cd "$env:USERPROFILE\plugins\hades-openspec-workflow"
git pull
```

如果 `%USERPROFILE%\.agents\plugins\marketplace.json` 不存在，创建 personal marketplace：

```powershell
$dir = "$env:USERPROFILE\.agents\plugins"
New-Item -ItemType Directory -Force -Path $dir | Out-Null
$json = @'
{
  "name": "personal",
  "interface": {
    "displayName": "Personal"
  },
  "plugins": [
    {
      "name": "hades-openspec-workflow",
      "source": {
        "source": "local",
        "path": "./plugins/hades-openspec-workflow"
      },
      "policy": {
        "installation": "AVAILABLE",
        "authentication": "ON_INSTALL"
      },
      "category": "Productivity"
    }
  ]
}
'@
$utf8NoBom = New-Object System.Text.UTF8Encoding($false)
[System.IO.File]::WriteAllText("$dir\marketplace.json", $json + [Environment]::NewLine, $utf8NoBom)
```

如果 marketplace 已经存在，不要整体覆盖文件，只追加或确认 `hades-openspec-workflow` 条目。

安装插件：

```powershell
codex plugin add hades-openspec-workflow@personal
codex plugin list
```

如果 WindowsApps 版 `codex.exe` 提示 `Access is denied`，可尝试使用实际安装路径中的 `codex.cmd`。

## 更新插件

团队成员更新插件源码：

```bash
cd ~/plugins/hades-openspec-workflow
git pull
codex plugin add hades-openspec-workflow@personal
```

Windows：

```powershell
cd "$env:USERPROFILE\plugins\hades-openspec-workflow"
git pull
codex plugin add hades-openspec-workflow@personal
```

更新后需要重启 Codex App，或在目标项目新开会话。已打开的旧会话不会自动重新加载新增或修改后的 skills。

## 验证是否安装成功

在 Codex 新会话中问：

```text
请列出当前会话可用的 hades-openspec-workflow skills。
```

也可以直接试：

```text
请使用 Hades OpenSpec Workflow 处理这个需求：给订单增加导出功能。先生成 PRD，不要写代码。
```

如果提示没有相关 skill：

1. 执行 `codex plugin list`，确认 `hades-openspec-workflow@personal` 是 installed/enabled。
2. 确认 marketplace 条目路径是 `./plugins/hades-openspec-workflow`。
3. 确认本地源码目录是 `~/plugins/hades-openspec-workflow` 或 `%USERPROFILE%\plugins\hades-openspec-workflow`。
4. 重启 Codex App 或新开会话。
